# 学生小档案

老师在本机管理班级和学生资料，学生可通过同一 Wi-Fi、手机热点或 ngrok 公网链接填写。文字和照片存储在老师电脑的 SQLite 数据库中。

## Windows 免配置版

`dist/StudentAlbum-Windows-x64-v0.2.zip` 是给 Windows 10 / 11 64 位电脑使用的便携包。它包含 Python、Pillow 和 ngrok，不需要另行配置开发环境。

1. 把压缩包完整解压到桌面或“文档”文件夹。
2. 双击“安装并启动学生小档案.cmd”。
3. 桌面会生成带应用图标的“学生小档案”快捷方式并自动打开管理页。
4. 以后只需双击桌面的图标。

便携包不会包含开发电脑上的数据库、学生资料或 ngrok 凭证。妈妈电脑上的资料保存在解压目录的 `app/data/album.sqlite3`，移动应用前应同时移动整个文件夹。

## 日常使用

1. 在 Mac 双击 **启动学生档案.command**，保持窗口开启、电脑联网且不休眠。
2. 首次使用，在老师管理页的「本学期班级」填写学期和班级。多个班级可用逗号、顿号或换行分隔；之后可继续添加，重名不重复创建。
3. 在「公网连接设置」粘贴 ngrok Authtoken，点击「保存并连接」。令牌从 [ngrok 账号页面](https://dashboard.ngrok.com/get-started/your-authtoken) 获取，只保存在本机的 `.runtime/ngrok.yml`，不进入 Git。
4. 连接成功后，管理页显示实际 HTTPS 公网网址，点击「复制填写链接」发给学生。手机不需要和电脑在同一个 Wi-Fi。
5. 学生选择班级、填写学号姓名并保存续填口令，随后填写资料和上传照片。
6. 老师名单每 3 秒自动刷新，可以按班级标签切换，查看和修改资料、导出名单；忘记续填口令可在学生详情中重置。
7. 删除学生后资料进入回收站；回收站按班级归类，可恢复单个学生或一键恢复整个班级。删除含学生的班级时，班内学生也会进入回收站。

ngrok 免费入口可能先显示 Visit Site 提示，按提示继续。网络异常时管理页显示具体连接状态并清除旧链接，可点击「重新连接」。运行期间持续读取实际网址。

老师管理页：[本机工作台](http://127.0.0.1:8765/admin.html)。学生本机预览：[填写页](http://127.0.0.1:8766/)。这两个本机网址不能直接在手机访问。

按 Control+C 或关闭启动窗口停止服务，数据库会保留。旧的「启动演示.command」仍可用，会转到正式启动入口。

### 同一 Wi‑Fi / 热点收集

不使用 ngrok 时，可运行 `python3 scripts/serve.py --local --lan`。老师电脑与学生手机连接到同一个 Wi‑Fi 或老师手机热点后，管理页会显示 `http://局域网地址:8766/`。这个入口只提供学生填写页和提交接口；老师管理页仍只能在电脑本机打开。学生离开该网络后链接失效。

## 数据和身份

- 新安装没有班级和学生，不含示例记录。未配置班级时学生页显示等待提示。
- `data/album.sqlite3` 保存班级、文字资料、续填凭证散列、会话和照片。照片以 JPEG 二进制存储，实际保存完整图片，最大边优化为 1800 像素并移除照片元数据。
- 学号在每个班级内唯一；不同班可有相同学号。续填使用「班级 + 学号 + 六位口令」，换手机或服务重启后仍可继续。
- 文字输入停顿后自动保存，失败时明确提示并重试；不会在保存失败时显示完成。当前标签页暂存未提交文字，关闭前有未保存提醒。照片上传失败需重新选择上传。
- 老师端仅监听本机 8765 端口，ngrok 只转发学生端 8766。学生只能查看和修改自己已登录的档案。
- 本机管理依赖当前电脑的登录环境，尚未增加独立的老师密码；不要在不受信任的共享电脑账户中运行。
- 班级支持新增和删除。删除空班级会直接移除；删除含学生的班级会将学生移入回收站，恢复该班级即可一并恢复学生。
- 数据和 ngrok 凭证均已忽略 Git。备份时先停止程序，再复制整个 `data` 文件夹到安全位置；导出的 CSV 仅含文字，不包含照片。

## 运行与验证

依赖 Python 3 和 Pillow。启动器在缺少 Pillow 时创建项目内虚拟环境并安装 `requirements.txt`，ngrok 缺失时从官方源下载。

仅本机运行：`python3 scripts/serve.py --local`。

集成测试：`python3 scripts/test_app.py -v`。测试在临时目录建立数据库，覆盖空数据、多班级、重复建档、照片、重启续填、访问隔离和口令限流，不写入正式 `data`。

生成 Windows 便携包：`python3 packaging/build_windows.py`。

`v0.1` 为最初学生端原型快照；`v0.2` 为带正式老师管理端、数据库、回收站和 Windows 免配置启动包的版本。
