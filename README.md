# 学生小档案 · 演示版

在 Mac 上双击 **启动演示.command**，老师管理页会自动打开。

- 首次使用自动下载 ngrok 官方程序到 `.runtime/`。需要网络和 Python 3。
- 若还未配置 ngrok，启动窗口会要求输入账号 Authtoken（输入隐藏）。从 https://dashboard.ngrok.com/get-started/your-authtoken 获取；不必发送给任何人。令牌只保存在忽略提交的 `.runtime/ngrok.yml`。
- 同一 Wi-Fi 下也可使用管理页显示的局域网链接。手机应与电脑连接同一网络，系统防火墙若询问，允许 Python 接收入站连接。
- 启动后点击老师管理页的「复制填写链接」，发到手机打开。ngrok 若显示访问提示，点击 Visit Site 继续。
- 测试期间保持电脑联网、唤醒，保留启动窗口。按 Control+C 或关闭窗口停止。
- 再次启动只需双击同一个文件。端口 8765 / 8766 被占用时先关闭旧演示。

老师管理页：http://127.0.0.1:8765/admin.html  
学生本机预览：http://127.0.0.1:8765/

只想看本机效果：`python3 scripts/serve.py --local`。

## 本次范围

- 学生端：手机自适应、小屏自然滚动、安全区、16px 输入字号；建档、续填和本地暂存。
- 老师端：桌面网页、6 位虚构示例、搜索、状态筛选、详情弹窗、导出示例 CSV、复制手机链接。
- 手机入口只提供学生页及其静态资源，老师页在另一个仅本机使用的端口。
- **手机资料保存在当前浏览器 localStorage，不会同步到老师电脑。** 换浏览器或访问域名也不会共享。照片仍只记录文件名。这是界面演示，不是正式收集服务。
- ngrok 连接异常时老师页显示错误，本机预览仍可用。详见 `.runtime/ngrok.log`（无需提交）。
