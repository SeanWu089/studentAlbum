学生小档案（Windows 10 / 11 64 位）

第一次使用
1. 先把整个压缩包解压到桌面或“文档”文件夹，不要直接在压缩包里运行。
2. 双击“安装并启动学生小档案.cmd”。
3. 桌面会出现带图标的“学生小档案”快捷方式，管理页面会自动打开。

以后使用
双击桌面的“学生小档案”图标即可。程序已经包含运行环境，不用另外安装 Python。

学生手机填写
- 双击桌面“学生小档案”后，本地服务、局域网入口和 ngrok 公网入口会自动启动。
- 同一 Wi-Fi 或热点：在管理页复制“局域网填写入口”。
- 不在同一网络：在管理页复制“公网填写入口”。公网入口使用固定 ngrok 地址并显示连接状态。
- 日常使用不需要再次输入 ngrok Authtoken，也不需要手动点击连接。

资料位置
所有班级、学生文字和照片都保存在 app\data\album.sqlite3。
备份时请复制整个 app\data 文件夹。

注意
- 不要移动或删除解压后的文件夹，否则桌面快捷方式会失效。
- Windows 可能首次询问是否允许本机网络访问，请选择允许“专用网络”。
- ngrok 需要外网；同一 Wi-Fi/热点入口不需要外网。
- 从旧版更新时，“安装并启动学生小档案.cmd”会自动沿用旧版已保存的 ngrok 配置。
