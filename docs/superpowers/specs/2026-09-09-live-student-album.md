# 多班级真实收集版本

依据本轮要求，沿用现有浅色与墨绿界面直接接入真实存储。数据库从空环境启动，不迁移浏览器里的旧演示数据，不预设班级或学生。

管理端增加本学期名称、批量添加班级输入栏及已有班级标签；名单按班级、状态、关键词筛选。学生建档和续填均选择班级，唯一身份为班级与学号组合。班级保存后学生端通过公共班级接口读取，管理名单每 3 秒刷新。

Python 本地服务分为老师回环端口 8765 和学生回环端口 8766，ngrok 只连接后者。SQLite 保存班级、学生、加盐口令散列、有效期会话及照片。照片保存在数据库内，以便文字与照片一并备份，替代初始设计的独立照片文件夹。

学生 API 使用仅属于该学生的随机 Bearer 会话。续填口令散列存储，失败登录限流；图片实际解码验证、压缩并移除元数据。管理 API 限定本机 Host、Origin 和运行时管理凭证，拒绝从学生端访问。

管理页从运行中的 ngrok 读取实际公网网址，区分缺少令牌、连接中、已连接和失败状态。首次令牌在本机管理页输入、只写入忽略版本管理的私有文件；不提供局域网地址替代公网状态。

本轮覆盖真实收集所需的班级、档案、照片、自动保存、续填、老师浏览、CSV 导出和本机口令重置。独立老师密码、班级归档/删除、扫码、自动备份不在此轮实现；README 明确当前行为。

验收使用临时数据库：班级录入 → 手机尺寸建档 → 自动保存 → 照片上传 → 管理端更新 → 重启恢复；检查学生端无法访问管理或数据库。正式数据库保持空白供用户首次录入。
